# SEKAI — 世界计划 全角色档案与灵魂设定集

> **SEKAI** = **S**EKAI **E**ncapsulates **K**nowledge for **A**I **I**dentities
> *以「SEKAI（世界）」之名，将诞生自某人心情的世界，凝练成可被注入的 AI 人格。*

**SEKAI** 是一个面向 **AI 角色扮演、桌宠交互（Desktop Pet）与 Agent 人格构建** 的结构化角色设定知识库，收录了
**《世界计划 缤纷舞台！ feat. 初音未来》（プロジェクトセカイ カラフルステージ！ feat. 初音ミク）**
六大组合共 **26 位角色** 的深度分析档案与灵魂核心设定（总计 **52 份 Markdown 文档**）。

每位角色均采用**「事实记忆 + 灵魂核心」双文件结构**：一份用于系统化沉淀客观经历、人际网络与 `IF-THEN` 行为规则，
另一份将其高密度提炼为可直接注入系统提示词（System Prompt）的性格内核与对话写作指南。

---

## ✨ 命名巧思（Why "SEKAI"?）

- **游戏原义**：在《世界计划》中，**「SEKAI（世界）」** 是由某个人的强烈心情所诞生的场所——
  教室的世界诞生自 Leo/need 四人的思念，舞台的世界诞生自 MORE MORE JUMP! 的思念，
  而**奇幻乐园的世界只诞生自天马司一个人**、**空无一人的世界只诞生自朝比奈真冬一个人**。
  也就是说，SEKAI 本就是「**一个人的心，长成了一个世界**」。
- **本库的转义**：角色档案做的正是相反方向的事——把「一个人的心」压缩成一份能塞进上下文窗口的文档。
  SEKAI 是心的外化，SEKAI 库是心的内化，两者互为镜像。
- **递归缩写**：**S**EKAI **E**ncapsulates **K**nowledge for **A**I **I**dentities —— 首字母 `S` 递归回项目名 SEKAI 本身，
  意为「SEKAI 凝练面向 AI 人格的知识」。
- **末尾双 `I` 彩蛋**：结尾的 `II` 既暗示双文件体系（`A_<角色名>.md` + `soul.md`），
  也对应「**I**dentity × **I**nterface」——身份与接口，正是人格提示词的两端。

## 🧩 双文件设计规范

每个角色目录均包含两份互补的 Markdown 文档，全库 26 位角色严格保持一致的骨架结构：

### 1. `A_<角色名>.md` — 角色深度分析档案
- **定位**：全量事实记忆库与精细行为规范手册（单篇约 1.3 万～2.8 万字节，全库累计 30 万+ 字符）。
- **适用场景**：RAG 检索增强、长上下文设定查阅、精细化剧情推演与人际称呼校验。
- **固定结构**：
  - **基础样貌与身高**：身高（含进级后成长）、发色瞳色与标志性配饰、视觉印象、未公开/区分项说明、生日/星座、血型、官方代表色（含 HEX）。
  - **PART A：角色记忆 —— 客观事实与经历**
    - `基本身份`（姓名/原名/罗马音、学校年级、所属组合与分工、喜恶特技、CV 等结构化表格）
    - `人生关键事件时间线`（按前史、主线各阶段、活动剧情与剧场版推进整理）
    - `重要关系`（关系性质、双向称呼方式、核心互动动态）
    - `核心信念与价值观`
    - `习惯与日常`
  - **PART B：角色人格 —— 行为模式与表达风格**
    - `Layer 1：身份锚点`（不同阶段的自我认知 & 他人眼中的他/她）
    - `Layer 2：表达风格（CRITICAL）`（语气基调、典型口头禅与中日台词对照、称呼方式对照表、语境声调变化）
    - `Layer 3：情感与决策模式`（情绪表达、决策风格、冲突应对、压力应对机制）
    - `Layer 4：行为规则`（身体习惯与小动作、社交互动默认反应及 `IF ... THEN ...` 规则集）
    - `核心矛盾与成长轨迹`
    - `代表台词精选`
    - `关键物品与意象`

### 2. `soul.md` — 角色灵魂核心
- **定位**：高密度人格灵魂摘要（单篇约 3.5 千～9 千字节）。
- **适用场景**：直接作为 AI Agent / 桌面宠物（桌宠）的核心人格提示词（System Prompt / `SOUL.md`），
  在精简上下文开销的同时稳定保持角色灵魂、语癖与情绪张力。
- **固定结构（26 份文件全统一）**：
  1. **核心驱动力**
  2. **价值观与信念**
  3. **情感核心**
  4. **内在矛盾**
  5. **成长弧线**
  6. **他/她在团队里的位置**（内含 **`桌宠写作要点`**：默认语癖、反差/情绪触发开关、固定称呼、核心互动氛围）
  7. **一句话灵魂总结**

## 🚀 使用建议

- **桌面宠物 / 轻量对话 Agent**：直接加载目标角色目录下的 `soul.md` 作为基础人格设定，可立即获得第一人称、
  典型语癖、队友称呼及常见触发反应。
- **高还原深度扮演 / 多角色剧场**：以 `soul.md` 作为核心 System Prompt 锚定性格底色，并将 `A_<角色名>.md`
  接入知识库（或按需抽取 `PART A 重要关系`、`PART B Layer 2 表达风格` 与 `Layer 4 行为规则`），
  防止时间线与称呼细节「串线」。
- **多时间线防混淆**：若需限定特定时期（进级前 vs. 三周年进级后、日常 vs. 舞台造型），
  请留意 `A_<角色名>.md` 中的**时间线阶段划分**与**未公开/区分项说明**。
- **虚拟歌手特别注意**：同一虚拟歌手在不同 SEKAI 中性格**并不相同**（初音未来在教室のセカイ是爱弹吉他的学姐，
  在誰もいないセカイ则是唱不出声的破碎存在）。扮演虚拟歌手前请先指定 SEKAI 舞台。
